# Theme Specification: Custom

## Overview
**Design Philosophy**: A blank, neutral canvas. Stays out of the user's way.
**Intended Feeling**: Neutral, invisible, unopinionated.

## Visual Language
- **Color Direction**: Standard OS-default greyscale. True white, true black, standard blue for actions.
- **Typography Direction**: System default font (San Francisco / Roboto).
- **Shape Language**: Standard 8px or 12px rounded rectangles.
- **Card Style**: Basic slight elevation. Standard borders.
- **Icon Direction**: System default icons.
- **Background Direction**: Standard OS background color.
- **Animation/Motion**: Standard OS transitions.

## Widget Integration
**Widget Style**: Renders widgets in their most generic, universally understood format.

## Accessibility & Use Cases
- **Accessibility Considerations**: Relies entirely on OS-level accessibility defaults.
- **Example Use Cases**: Users who skipped the persona survey or want a totally standard, baseline UI to build upon.

## What Makes It Visually Distinct
It is distinctly un-distinct. It looks exactly like a standard default app.
