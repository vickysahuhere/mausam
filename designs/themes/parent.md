# Theme Specification: Parent

## Overview
**Design Philosophy**: Reassuring, soft, and highly accessible. Rapid answers for busy people.
**Intended Feeling**: Safe, warm, soft, immediate.

## Visual Language
- **Color Direction**: Soft primary colors (calm blues, soft yellows) that aren't overly saturated.
- **Typography Direction**: Friendly, highly legible, larger default font sizes.
- **Shape Language**: Chunky, soft rectangles. Very forgiving tap targets.
- **Card Style**: Large, distinct blocks. Color-coded heavily (e.g., Blue for rain, Yellow for sun) so it can be read across a room.
- **Icon Direction**: Illustrative, slightly playful but highly descriptive.
- **Background Direction**: Warm white or soft pastel.
- **Animation/Motion**: Gentle, non-jarring transitions.

## Widget Integration
**Widget Style**: Focus on 'Yes/No' answers (e.g., 'Will it rain on the school run?').

## Accessibility & Use Cases
- **Accessibility Considerations**: Maximum legibility, large tap targets for one-handed use.
- **Example Use Cases**: Parents checking conditions quickly while wrangling kids.

## What Makes It Visually Distinct
Large, friendly, color-coded blocks for split-second readability.
