# Mausam Themes Registry

This directory contains the visual specifications for Mausam's first-class themes. 

These specifications act as guidelines for creating the TypeScript theme objects. They define the intended emotion, color palettes, and structural rules for each theme.

### Available Specifications
- `apple-liquid.md`
- `retro-peaceful-2d.md`
- `health.md`
- `fitness.md`
- `beach.md`
- `travel.md`
- `parent.md`
- `agriculture.md`
- `commuter.md`
- `event.md`
- `custom.md`

### Note on Implementation
Do **not** copy proprietary or copyrighted assets from other companies when implementing these specifications. These are visual direction documents meant to inspire original styling values within the `MausamTheme` constraints.
